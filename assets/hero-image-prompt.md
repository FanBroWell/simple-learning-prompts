# Hero Image Generation Prompt

## Positioning

**Show one complete generated lesson instead of a generic list of answer types.**

- Pain: the student searched for answers but still does not understand.
- Action: copy the reusable Prompt and send it with the question.
- Generated lesson: visualize the concept, connect it to real life, calculate step by step, and finish with a new understanding-check problem.
- Concrete example: teach the Pythagorean theorem through a 3–4–5 triangle, a ladder against a wall, exact calculations, and a 6–8–? practice question.
