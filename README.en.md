## 🌿 Why "Simple + Sustainable"

The biggest enemy of learning isn't difficulty — it's **"too much hassle, can't keep it up."**

So this library does exactly two things:

> ### 🟢 Simple — so simple there's no mental barrier
> Every template is **one line**. Copy, fill in, send. No need to "get in the zone" — just ask anytime, anywhere.
>
> ### 🔵 Sustainable — a little each day, compounding automatically
> Don't try to learn it all at once. Understand one small point today, save it to your notes; another tomorrow. **Look back in a year — you've built a mountain of knowledge.**

**Motto: one small bite, every day, beats one heroic cram session a hundred times over.**

---

## 🚀 Start in 30 Seconds (really that simple)

1. Whenever something confuses you — a problem, a word, a paragraph, a kid's question.
2. Copy the matching **one-line template** below.
3. Replace the `【】` with your content (or just attach a screenshot).
4. Send it to any AI (ChatGPT / Claude / Gemini / etc.).
5. **Save it to your notes.** Done — today's "little bit" is in.

> 💡 The key habit: **save one entry to Notion / Notes each time.** You're not collecting notes — you're collecting a smarter you.

---

## 🧩 The Core Formula (the soul of every template)

> **Plain language + What's the core concept + Why + An example a child would get + How to remember it**

Even if you forget the templates, remember this one line and you'll ask great questions on your own.

### 1. 🎓 Understand a concept (most used)

```
Please explain 【the concept I want to learn】.
1. Use plain language, no jargon;
2. First tell me what problem it actually solves (the core idea);
3. Explain the "why", don't just give the conclusion;
4. Give a real-life example a child could understand;
5. Give me a memorable hook / mnemonic.
Use clear bullet points so I can save it to my notes.
```

### 2. ✏️ Stuck on a problem

```
Help me analyze this problem 【paste the problem / screenshot】. Don't just give the answer:
1. What concept does it test, and why is it tested this way;
2. Why each option/step is right or wrong;
3. Use a kid-friendly example to help me grasp the core;
4. How to quickly recognize this type of problem next time.
Plain language, bullet points.
```

### 3. 👶 Your kid asked something

```
I need to explain 【topic / my kid's question】 to a 【grade level】 child, but I'm not sure how myself. Please:
1. Use plain language a child that age can understand;
2. Give an example the child knows (toys / snacks / games);
3. Suggest a small hands-on activity we can do together;
4. Warn me what the child most easily gets confused about.
```

### 4. 📄 A passage/paper you can't parse

```
Help me understand this passage 【paste content / screenshot】. Paragraph by paragraph:
1. Translate/paraphrase it clearly;
2. Explain in plain language what it's saying;
3. Give a kid-friendly example;
4. Say what it's actually doing.
For any formula, translate every symbol into plain words.
```

### 5. 💼 Get into something new fast

```
I want to quickly understand 【field / skill】, as a total beginner. Please:
1. Explain in plain language what it is and what it solves for me;
2. Build intuition with a real-life example;
3. The 3 core concepts I should learn first;
4. The shortest path to learning it + common pitfalls.
```

### 6. ❓ Still don't get it

```
I mostly followed the above, but 【the specific step/part】 still doesn't click, especially 【where I'm stuck】.
Explain it a simpler way, with a brand-new kid-friendly example, and drill just this one point.
```

### 7. 📝 Make today's learning stick

```
Summarize what I learned today about 【topic】 into a knowledge map:
1. Go from the big picture down to details;
2. Give each point one plain-language line + a memory hook;
3. Flag the easiest pitfalls;
4. End with one sentence capturing the core.
Format it cleanly so I can save it to Notion long-term.
```

## 🔁 Turn It Into a Daily Habit

> Don't force it — the simpler it is, the easier to keep up.

- **🎯 Just one thing**: understanding one small point a day counts as a win. Don't overreach.
- **📸 Snap and ask**: problems, errors, textbooks, a kid's question — screenshot and send, zero typing.
- **📋 Always save**: save entries one by one into Notion / Notes — this is the key to "sustainable".
- **🔂 Keep asking**: use #6, dig layer by layer until "oh, I get it now."
- **🧪 Quiz yourself sometimes**: add "give me 3 questions to test me" — you'll remember best.
- **📅 Look back**: review your notes once a week — you'll be amazed how much you now understand.
