# 🌱 每天懂一点
### 简单 · 能坚持的 AI 学习提示词
**Simple Learning Prompts**

**身边没人能问的时候,把 AI 变成那个「随叫随到、还讲得懂」的老师。**
一个万能模板,复制填空就能用。不用毅力,不用规划,每天弄懂一点,慢慢攒成你自己的知识库。

`一个模板走天下` · `随时能问` · `小学生也能懂的例子` · `越攒越懂` · `可存 Notion`

</div>

## 😣 它想解决的两个痛点

### 痛点一:学生自学,卡住了却没人问
晚上写作业、周末刷题、考前复习——**偏偏这些时候老师不在身边**。
一道题卡住,一个概念绕不过来,只能干瞪眼;问题越攒越多,越攒越不想学。
搜题软件只给答案,不讲"为什么";看视频又太长、找不到正好那一句。
**你需要的,是一个能随时把这一个点讲到你懂的人。**

### 痛点二:家长想帮孩子,却不知道怎么讲
孩子拿着题来问,你也想帮——
可要么**自己也忘了/没学过**,要么**懂,但不知道怎么用孩子听得懂的话讲出来**,
一急,亲子关系还容易闹僵。
**你缺的不是耐心,是一个"把课本翻译成孩子能懂的话 + 配个好例子"的帮手。**

> 这个库就干一件事:**让"没人解答"和"不会讲"这两件事,不再是障碍。**

---

## ⭐ 一个万能模板(这就是全部)

不用记 7 个模板,**只记这一个,什么场景都能用**。复制,把 `【】` 换成你的内容,发给任意 AI 即可(可以直接连题目/课本截图一起发)。

```
我在学【要弄懂的东西:一个概念 / 一道题 / 一段话 / 孩子问的问题】,身边没人能问。
请帮我讲明白:
1. 用大白话,不要术语;
2. 先说它到底在讲什么、解决什么问题(核心知识点);
3. 讲清楚"为什么",别只给结论;
4. 用一个小学生也能听懂的生活例子来类比;
5. 给我一个好记的记忆钩子 / 口诀;
6. 如果我还没懂,我会追问,请你换个更简单的说法和新例子再讲一遍。
分点排版,方便我存进笔记。
```

**发给任意 AI:ChatGPT / Claude / 豆包 / 文心 / 通义 / DeepSeek… 都行。**

---

## 🎛️ 按场景,加一句话就够

同一个模板,针对不同情况**在开头补一句**,效果立刻对味:

| 你的情况 | 在模板开头加这句 |
|---|---|
| 👶 **家长辅导孩子** | "我要讲给【几年级】的孩子听,请用他这个年龄能懂的话和例子,再给我一个能和他一起做的小互动。" |
| ✏️ **做题不会** | "这是一道题【贴截图】,别只给答案,请讲清每个选项为什么对/错,以及下次怎么快速判断。" |
| 📄 **文献/长段落看不懂** | "请逐段翻译+大白话解释,遇到公式把每个符号都翻译成人话。" |
| 💼 **快速入门新技能** | "我是完全新手,请顺便告诉我最该先掌握的 3 个核心概念和常见的坑。" |
| ❓ **还是没懂** | "上面我大概懂了,但【某一点】还没转过弯,请换个全新的小学生例子只讲这一点。" |
| 📝 **想记牢/复习** | "最后帮我把这个主题总结成一张知识地图,每点配一句大白话+记忆钩子。" |

---

## 🧩 核心公式(模板的灵魂)

> **通俗大白话 + 这考什么知识点 + 为什么 + 小学生例子 + 怎么记住**

哪天忘了模板也没关系——记住这一句,你自己就能随口问出好问题。

---

## 🔁 把它变成每天的小习惯

> 学习最大的敌人不是难,是"太麻烦坚持不下来"。越简单,越能一直走下去。

- **🎯 只求一点**:每天弄懂"一个小点"就算赢,别贪多。
- **📸 随手截图问**:题目、课本、报错、孩子的问题,截图直接发,零打字。
- **📋 学完必存**:一条条存进 Notion / 备忘录——这是"持续"的关键。
- **🔂 没懂就追问**:一层层问到"啊我懂了",不放过。
- **🧪 偶尔测自己**:加一句"出 3 道题考我",记得最牢。
- **📅 攒着回看**:一周翻一次笔记,你会惊讶自己懂了这么多。
