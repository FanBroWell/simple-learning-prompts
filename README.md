# 🌱 每天懂一点
### 简单 · 能坚持的 AI 学习提示词库
**Simple Learning Prompts**

**把「学习」变成一件简单到能天天做、越做越懂的小事。**
一句话模板,复制填空就能用。不用毅力,不用规划,每天懂一点,慢慢攒成你自己的知识库。

`一句就能用` · `每天都能学` · `越攒越懂` · `小学生也能懂的例子` · `可存 Notion`

</div>

---

## 🌿 为什么是「简单 + 持续」

学习最大的敌人不是难,是**"太麻烦,坚持不下来"**。

所以这个库只做两件事:

> ### 🟢 简单 —— 简单到没有心理负担
> 每个模板就是**一句话**,复制、填空、发送。不用先"准备好状态",随时随地问一句。
>
> ### 🔵 持续 —— 每天懂一点,自动越滚越大
> 不追求一次学完。今天弄懂一个小点,存进笔记;明天再一个。**一年后回头,你已经攒了一座知识山。**

**口诀:一次一小口,天天不间断,比"哪天猛冲一次"强一百倍。**

---

## 🚀 30 秒上手(真的很简单)

1. 遇到任何"没搞懂"的东西 —— 一道题、一个词、一段话、孩子的一个问题。
2. 复制下面对应的**一句话模板**。
3. 把 `【】` 换成你的内容(或直接连截图一起发)。
4. 发给任意 AI(ChatGPT / Claude / 豆包 / 文心…)。
5. **存进笔记**。就这样,今天的"一点"到手了。

> 💡 关键习惯:**每次学完存一条到 Notion / 备忘录。** 攒的不是笔记,是"越来越懂"的自己。

---

## 🧩 核心公式(所有模板的灵魂)

> **通俗大白话 + 这考什么知识点 + 为什么 + 小学生例子 + 怎么记住**

记不住模板没关系,记住这一句,你自己也能随口问出好问题。

### 1. 🎓 想弄懂一个概念(最常用)

```
请帮我讲清楚【要学的概念】。
1. 用大白话,不要术语;
2. 先说它到底解决什么问题(核心知识点);
3. 讲清楚"为什么",别只给结论;
4. 配一个小学生也能懂的生活例子;
5. 给我一个好记的记忆钩子/口诀。
分点排版,方便我存笔记。
```

### 2. ✏️ 一道题不会

```
帮我分析这道题【贴题目/截图】。别只给答案:
1. 这题考什么知识点、为什么这么考;
2. 每个选项/步骤为什么对、为什么错;
3. 用小学生例子帮我理解核心;
4. 下次遇到同类题怎么快速判断。
通俗、分点。
```

### 3. 👶 孩子问了个问题

```
我要给【几年级】孩子讲【知识点/孩子的问题】,我自己也不太会讲。请:
1. 用孩子这年龄能懂的大白话;
2. 配一个孩子熟悉的例子(玩具/零食/游戏);
3. 给我一个能和孩子一起做的小互动;
4. 提醒孩子最容易搞混的地方。
```

### 4. 📄 一段话/文献看不懂

```
帮我读懂这段【贴内容/截图】。逐段:
1. 翻译成中文;
2. 大白话解释在讲什么;
3. 配小学生例子;
4. 说它实际在干什么。
遇到公式,把每个符号都翻译成人话。
```

### 5. 💼 想快速入门新东西

```
我想快速搞懂【领域/技能】,完全新手。请:
1. 大白话讲它是什么、能帮我解决什么;
2. 用生活例子建立直觉;
3. 最该先掌握的 3 个核心概念;
4. 学会它的最短路径 + 常见的坑。
```

### 6. ❓ 还是没懂

```
上面我大概懂了,但【具体哪一点】还是没转过弯,尤其是【卡住的点】。
换个更简单的说法,用一个全新的小学生例子,把这一点单独讲透。
```

### 7. 📝 今天学的想记牢

```
把我今天学的【主题】总结成一张知识地图:
1. 从整体到细节梳理;
2. 每个点配一句大白话 + 记忆钩子;
3. 标出最容易踩的坑;
4. 一句话概括核心。
方便我复制到 Notion 长期保存。
```

## 🔁 把它变成每天的小习惯

> 不用逼自己,越简单越容易坚持。

- **🎯 只求一点**:每天弄懂"一个小点"就算成功,别贪多。
- **📸 随手截图问**:题目、报错、课本、孩子的问题,截图直接发,零打字。
- **📋 学完必存**:一条一条存进 Notion / 备忘录,这是"持续"的关键。
- **🔂 没懂就追问**:用 #6,一层层问到"啊懂了",不放过。
- **🧪 偶尔测自己**:加一句"出 3 道题考我",记得最牢。
- **📅 攒着看**:一周回看一次自己的笔记,你会惊讶自己懂了这么多。
