# 不是你学不会，是一直没人把它讲明白。

### 遇到问题，复制 Prompt，把题目一起发给 AI。

让 AI 像一位耐心的一对一老师：不只报答案，而是讲知识点、讲“为什么”、换例子，并检查你是否真的懂了。

**一个模板，复制就能用。**

`题目截图直接问` · `大白话讲知识点` · `追问到懂` · `复述检查理解`

</div>

---

> **这不是又一个 Prompt 合集。** 这个仓库只解决一个问题：当你学习卡住、身边没人能问时，让 AI 把眼前这个知识点像老师一样讲到你懂。

## 🚀 30 秒开始

1. 遇到不会的题目、概念或段落，先截图或复制下来；
2. 复制下面的万能 Prompt；
3. 把 `【】` 换成你的问题，并把题目文字或截图一起发给 AI；
4. 哪里没懂就指出哪里，让它换一种说法、换一个例子继续讲；
5. 最后用自己的话复述一遍，让 AI 帮你找到真正卡住的那一步。

支持 ChatGPT、Claude、DeepSeek、Gemini、豆包、通义等对话式 AI。

## ⭐ 万能 Prompt：把 AI 变成随时能问的学习老师

复制整段，把 `【】` 替换成你的内容：

```text
请像一位耐心的一对一老师一样帮助我。

我正在学习【科目 / 主题】，这是我遇到的问题：
【粘贴题目、概念或段落，也可以直接上传截图】

我已经查过资料，但还是没有真正弄懂。请不要只给答案，而是把它讲到我能自己复述出来：

1. 先判断这道题或这个问题真正考查什么知识点；
2. 用大白话解释核心概念，不要一上来堆术语；
3. 一步一步讲清楚“为什么”，不要跳步骤；
4. 配一个生活中的简单例子，帮我建立直觉；
5. 如果有解题过程，解释每一步为什么这样做；
6. 提醒我最容易理解错或做错的地方；
7. 如果我说“还是没懂”，请换一种说法和一个全新的例子，只讲我卡住的那一点。

讲完后，请先让我用自己的话复述一次。根据我的复述指出具体是哪一步没理解，再给我一道很短的检查题，确认我真的会了。
```

## 🧭 它不是替你做题，而是完成“老师会做的四步”

| 学习时真正需要的帮助 | 这个 Prompt 会让 AI 怎么做 |
|---|---|
| **先找到卡点** | 判断题目在考什么，而不是马上扔出答案 |
| **把知识讲明白** | 用大白话、步骤和生活例子建立直觉 |
| **允许反复追问** | 没懂就换一种说法，只讲卡住的那一点 |
| **确认真的学会** | 让你复述、纠错，再用一道小题检查 |

你得到的不只是“这一题的答案”，而是一轮完整的：

> **遇到问题 → 提问 → 听懂 → 复述 → 纠错 → 会做同类题**

## 🔍 为什么普通提问经常没用

| 普通问法的问题 | 这个模板怎么解决 |
|---|---|
| “告诉我答案”只能完成眼前这题 | 先找到核心知识点，再解释为什么 |
| 第一次解释太抽象 | 要求换一种说法和全新的生活例子 |
| 当时觉得懂了，过后又忘 | 加入记忆钩子、复述和检查题 |
| 不知道自己究竟卡在哪里 | 让 AI 根据你的复述定位误解的那一步 |

## 🧪 一个很短的对比

问题：**为什么负负得正？**

**只问答案时：**

> 这是数学规定：两个负数相乘得到正数。

你知道了规则，但仍然不知道为什么。

**使用这个 Prompt 后：**

- 先说明它和乘法规律、数轴方向有什么关系；
- 再用“撤销一笔欠款”等生活类比建立直觉；
- 一步一步解释为什么规律必须保持一致；
- 让你用自己的话复述；
- 最后用一道简单变式检查你是否真的理解。

区别不在于回答更长，而在于它更像一次真正的讲解。

## 🎛️ 不同场景，只需在 Prompt 前加一句

| 你的场景 | 加上这句话 |
|---|---|
| ✏️ **做题不会** | “别只给结果，请讲清每一步为什么这样做，以及下次怎么识别同类题。” |
| 📄 **文献或长段落看不懂** | “请逐段翻译成大白话，遇到公式把每个符号都解释成人话。” |
| 💼 **快速入门新技能** | “我是完全新手，请先告诉我最该掌握的 3 个核心概念和常见误区。” |
| 📝 **复习和记忆** | “最后整理成知识地图，每个点配一句大白话和一个记忆钩子。” |
| 👶 **家长辅导孩子** | “我要讲给【几年级】的孩子听，请使用他熟悉的生活例子，再设计一个小互动。” |

## 🔁 把一次答题变成真正的学习

- **先自己想一下**：告诉 AI 你已经想到哪一步，它更容易找到你的卡点；
- **没懂就继续问**：不要只说“看不懂”，指出具体是哪一句、哪一步没转过弯；
- **一定要复述**：能用自己的话讲出来，才是真的懂；
- **做一道变式题**：确认换个数字或问法后，你仍然会做；
- **保存真正的卡点**：把“我哪里理解错了”记下来，比只收藏答案更有用。

学生自学 · 考证考研 · 阅读论文 · 职场学习 · 家长辅导 · 任何“遇到问题，却暂时没人能讲明白”的时刻。
